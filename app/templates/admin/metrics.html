Metric Definitions
Accuracy Metrics
Precision
TP / (TP + FP)
Recall
TP / (TP + FN)
F1-Score
Harmonic mean of Precision and Recall.
IoU
Intersection over Union between the predicted bounding box and ground-truth bounding box.
Error Metrics
True Positive
A predicted face correctly matched to a ground-truth face.
False Positive
A predicted face that does not match a ground-truth face.
False Negative
A ground-truth face that was not detected.
IoU Threshold
This evaluation uses IoU ≥ 0.5 as the matching criterion.
